# Alfido Tech – Sales Performance Analysis

## 📊 Project Overview

This project was completed as part of the Alfido Tech Data Analyst Internship.

The objective of this project is to analyze sales performance across regions,
categories, products, customer segments and time.

## 🎯 Objectives

- Analyze overall sales performance
- Calculate key sales KPIs
- Compare sales across different regions
- Analyze category and sub-category performance
- Identify top and low-performing products
- Analyze monthly sales trends
- Identify seasonal sales patterns
- Provide actionable business recommendations

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- GitHub

## 📈 Key Analysis

The project includes:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Regional Sales Analysis
- Category Analysis
- Product Performance
- Monthly Sales Trends
- Seasonality Analysis
- Customer Segment Analysis
- Region × Category Analysis

## 💡 Business Recommendations

1. Strengthen high-performing regions.
2. Prioritize high-performing product categories.
3. Review low-performing products.
4. Plan inventory and promotions around seasonal demand.
5. Use customer-segment-based marketing strategies.
